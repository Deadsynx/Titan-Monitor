# Support

Si vous rencontrez un problème :

1. Vérifiez que vous utilisez la dernière version.
2. Consultez TitanMonitor.log.
3. Ouvrez une Issue GitHub.

Merci d'inclure :

- votre processeur
- votre carte graphique
- votre version de Windows
- le fichier TitanMonitor.log
- une capture d'écran si nécessaire
