# ✨ Fonctionnalités

## 📊 Monitoring en temps réel

- Température CPU
- Utilisation CPU
- Fréquence CPU
- Tension CPU

- Température GPU
- GPU Hotspot
- Température VRAM
- Utilisation GPU
- Tension GPU

- Utilisation RAM

- Stockage
  - SSD / HDD détectés automatiquement
  - Capacité
  - Espace utilisé
  - Espace libre
  - Santé (si disponible)

# 🚀 Installation

Téléchargez la dernière version :

```
TitanMonitorSetup.exe
```

Puis :

- Suivant
- Installer
- Terminer

Aucune installation de Python n'est nécessaire.

---

# 🔧 Compilation

Installer les dépendances :

```bash
pip install -r requirements.txt
```

Lancer Titan Monitor :

```bash
python main.py
```

Créer l'exécutable :

```bash
build.bat
```

# 🎯 Philosophie

Titan Monitor n'a pas vocation à afficher
500 capteurs incompréhensibles.

L'objectif est de fournir les informations réellement utiles
dans une interface moderne et lisible.
